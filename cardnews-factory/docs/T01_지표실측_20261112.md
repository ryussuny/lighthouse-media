## 4. 네이버 데이터랩
- 키 없음(`.env` 에 네이버 키 없음) → 실호출 못 함. 공식 문서 확인값(`docs/T01_policy_research.md`): **하루 1,000회, 요청당 주제어 묶음 최대 5개, 묶음당 검색어 최대 20개**, 2016-01-01부터, 값은 요청 안 최대값=100 상대값(요청끼리 직접 비교 금지 → 비교할 후보는 한 요청 안에 넣고, 5개 초과 시 공통 기준어를 매 요청에 넣어 이어 붙인다). 조회 기간 최대 길이는 확인 못함.
- 키 발급 경로: 네이버 개발자센터 애플리케이션 등록(데이터랩 검색어트렌드 사용 API 선택) — 오너 네이버 로그인이 필요해 **오너 손 단계**. 키가 오기 전까지 점수식은 "유튜브 조회 지표 + 인스타 반응 지표 + 트렌드 RSS 포함 여부"로 동작하고, 데이터랩은 키가 오면 켜는 선택 지표로 둔다.
