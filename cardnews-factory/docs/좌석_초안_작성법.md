# 좌석 초안 작성법 (1장)

> 종량 API 는 꺼져 있다. 글은 작성 좌석이 쓰고, 기계 관문(G1~G7)이 그대로 검사한다. 위치: `data/drafts/<날짜>/<계정>.json`

## 형식 — 순수 JSON 한 개
코드펜스(```)·머리말·설명 문장을 붙이면 **보류**된다. 필수 키가 하나라도 없거나 비면 compose 단계에서 보류.

```json
{
 "kw": "오늘 research 가 고른 키워드(정확히 같아야 함)",
 "author_surface": "작성 좌석 번호/이름 (예: 154)",
 "cards": [{"title": "...", "body": "..."}, ... 정확히 5장],
 "caption_body": "캡션 본문 2~3문장",
 "hashtags": ["태그(# 없이)", "... 권장 5개 이내(선택)"],
 "used_sources": ["https://… (이번 실행 sources_for_run 의 url 중 실제로 쓴 것만)"]
}
```

- `used_sources`: 이번 실행 출처 url 중 **내용을 실제로 가져다 쓴 것만**. 없음·빈 배열·이번 실행 출처에 없는 url·중복 url → 보류.
  G1(공식 기관 2곳)·G2(숫자 대조)·캡션 출처 줄이 모두 이 부분집합만 기준으로 돈다. 쓰지 않은 출처로는 기관 수도 숫자 대조도 통과할 수 없다.
  쓴 출처가 한 기관뿐이면 G1 에서 보류된다(그날은 게시 안 함 — 관문은 풀지 않는다).
- **기여 확인**: used_sources 의 기관은 그 기관 저장본에 **카드 본문(cards[].body)의 구별력 있는 숫자가 1개 이상 실제로 있어야** G1 기관 수에 든다. 제목·캡션·해시태그의 숫자는 세지 않고, 날짜성 숫자(연·월·일·시·분, 2026.11.04 꼴)와 저장본 전체에서 흔한 숫자(문서 빈도가 max(5건, 저장본의 2%) 초과 — '65세'·'10%' 같은 것)도 세지 않는다. 선언만 하고 내용에 안 쓴 기관은 빠지고(사유 "선언했지만 내용에 쓰이지 않은 기관"), 기관 2곳 미만이면 G1 보류(이때도 숫자 대조 진단이 사유에 같이 남는다). 같은 숫자가 두 기관 원문에 다 있으면 둘 다 기여로 인정(교차 확인). **카드 본문에 숫자(금액·인원·건수 등)가 하나도 없는 초안은 draft 모드에서 항상 G1 보류**다.
- url 은 이번 실행 출처 목록에서 **그대로 복사**한다. 틀리면 보류 사유에 가장 가까운 후보가 나오지만 자동 보정은 없다.
- `caption_body` 는 비면 보류. `hashtags` 는 배열이어야 하고(문자열이면 보류) 없어도 되지만 키워드 태그가 자동으로 붙는다 — 상한은 코드가 10개로 자른다(권장 5개).
- `sources`·`account_id`·`caption` 은 쓰지 않는다(써도 무시, 코드가 만든다).

## 쓰는 법
1. **출처 저장본만** 읽는다(research_ledger 오늘 마지막 ok 행 → `research.sources_for_run` → `saved_path`). 웹 검색·학습지식 금지.
2. 숫자는 **아라비아 숫자**, 저장본에 **그대로 있는 표기**만. 확신 없으면 뺀다. 단위 없는 숫자 금지.
3. 날짜(시행일·신청 기간·마감)가 원문에 있으면 **빼지 않는다**. 상대 날짜('내년'·'이달'·'올해') 대신 원문 기준 연·월·일.
4. 금액·혜택은 원문의 **대상 조건·차감·예외 단서**를 같이 쓴다. 예상치·'약'·'예정'은 그대로 옮긴다(혜택이 실제보다 커 보이면 안 됨).
5. **입법예고·계획·추진 단계는 제목에도 '입법예고'·'추진'·'예정' 등 단계를 표시**한다(확정·시행된 제도처럼 읽히면 안 됨).
6. 마지막 카드 본문 끝에 "신청 전 해당 기관에 꼭 확인하세요". 과장·낚시 표현·의료 단정·투자 권유 금지. 투자 계정은 모든 카드 본문에 계정 필수 고지 문구.
7. 쓴 뒤 `py -m json.tool <파일>` 로 형식만 확인. `run.py` 는 직접 돌리지 않는다(master).

## 검사·재작성
- **판정 좌석 점검(코드로는 못 막는 것)**: 각 기관의 숫자가 **그 기관 내용을 말하는 문장**에 쓰였는지 — 무관한 문장에 타 기관의 구별 숫자만 끼워 기관 수를 채운 초안이 아닌지 본다.
- G3: 키워드 금칙 → 다른 좌석(리뷰어)이 쓴 `<계정>.g3.json`(`ok`·`category:"none"`·`reviewer_surface`·`draft_sha256`=초안 파일 바이트 sha256). **g3.json 은 작성 좌석이 쓰지 않는다.**
- G2 만 실패하면 `<계정>.retry.json`(같은 형식, `used_sources` 포함)을 1회만 쓸 수 있다. 판정(g3)은 최종 초안 파일의 sha256 로 다시 받는다.
