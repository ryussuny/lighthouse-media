## 2. 투자 계정 범위(설계부터 조심)
- **다룰 수 있음**: 공식 기관이 낸 **제도**(ISA·연금저축·청년도약계좌 등 세제·가입 요건), **통계**(기준금리·물가·가계부채 발표 수치), **일정**(세금 신고·청약·제도 시행일), **세금**(금투세·배당소득 과세 같은 제도 설명), **주의보**(금감원 소비자 경보·불법 리딩방 주의).
- **다루지 않음**: 개별 종목·코인 이름을 든 추천, 매수·매도 시점, 수익률 전망, "지금 사라/팔아라", 수익 인증, 특정 상품 가입 유도.
- **모든 카드 하단 고지**: "투자 권유가 아닙니다. 투자 판단과 책임은 본인에게 있습니다." (G7 에서 계정별 필수 문구로 검사 — 코드 티켓 예정)
- **금칙 추가(계정 전용 banned_topics_extra + 공통 investment_solicit 보강)** — 자본시장법상 미등록 투자자문·유사투자자문·부당 권유로 볼 소지가 있는 표현:
  매수 추천, 매도 추천, 지금 사야, 지금 팔아야, 목표가, 목표 주가, 수익률 보장, 확정 수익, 고수익 보장, 손실 없는, 무위험 수익, 몇 배 오를, 텐배거, 급등 예상, 상한가 종목, 저평가 종목 추천, 종목 추천, 픽, 매매 신호, 시그널 방, 리딩, 유료 회원, 1:1 상담, 투자 자문, 카톡방 입장, 코인 추천, 에어드랍 (기존: 수익 보장·원금 보장·무조건 오르·급등 종목·리딩방·추천 종목·몇 배 수익·코인 추천).
  → 법률 판단은 아님. 문구 목록은 보수적으로 넓게 잡고, 걸리면 보류(사람이 확인).
- **솔직한 한계**: 이 범위는 '돈 버는 법' 콘텐츠보다 조회 수가 덜 나올 수 있다. 대신 계정 정지·법적 위험을 피한다.

## 3. 트렌드 계정
- 주제 원천: 구글 트렌드 KR·유튜브 인기 등 지표(이미 trends.py). 연예·사건사고·정치·의료 단정은 금칙 유지.
- '공식 기관 2곳' 관문에서 보류가 가장 많을 계정 → **보류율 실측 중(T-TR1, worker 152, 결과 `docs/트렌드_보류율_20261113.md`)**. 보류된 날은 게시하지 않는다(관문 유지).

## 4. 좌석 작성 흐름 (종량 API 0)
1. 매일 정해진 시각: `trends`(지표·순위) → `research`(공식 출처 수집·저장·sha256) — 사람·AI 호출 없음, 기계 실행.
2. **작성 좌석(worker)**이 그날 출처 저장본만 읽고 카드 초안 JSON 을 `data/drafts/<날짜>/<계정>.json` 에 쓴다(출처 밖 숫자·기관 금지, 아라비아 숫자, 5장).
3. `run.py --draft-file` 이 초안을 받아 **G1~G7 기계 검사**(출처 2기관·숫자 토큰 대조·키워드 금칙·중복·디자인·캡션)를 그대로 돈다.
4. G3 의 AI 분류기 부분은 종량 API 대신 **다른 좌석(리뷰어)**이 판정 파일을 쓴다(만든 좌석≠검증 좌석). 판정 파일이 없으면 보류.
5. 통과 → 카드·캡션 생성(1단계는 게시 0, 리허설 폴더). G2 실패 시 작성 좌석이 1회 다시 쓰기.
- **완전 자동과의 관계**: 기계 단계(1·3·5)는 무인. 글 쓰기(2)와 분류 판정(4)은 좌석이 켜져 있어야 한다. 정해진 시각에 작성 좌석이 없거나 응답이 없으면 **그날은 건너뛰고 작업실(폰)로 알림**. 무인 매일 게시로 가려면 그때 종량 API 를 월 상한과 함께 따로 승인받는다(1건 약 $0.028, 하루 3건 월 약 $2.5~5).
- 코드 변경(compose API 경로 기본 끔·`--draft-file`·판정 파일·투자 고지 검사·계정 3개 가상 설정)은 리뷰8 커밋 뒤 티켓으로 진행.

## 5. 오너가 계정 만들 때 따라 할 순서 (5줄)
1. 인스타 앱 → 프로필 → 계정 추가 → 새 계정 만들기(주제별 아이디·전화/메일 인증은 오너 손). 한 앱에 최대 10개 동시 로그인.
2. 새 계정 → 설정 → 계정 유형 및 도구 → **프로페셔널 계정으로 전환** → 크리에이터 또는 비즈니스 선택(개인 계정은 API 게시 불가).
3. 카테고리 고르고 연락처 공개는 끔(선택). 페이스북 페이지 연결은 건너뜀 — **Instagram Login 방식은 페이지가 필요 없다**.
4. PC 에서 부서가 안내하는 Meta 앱 연결 화면을 열고 그 계정으로 **Instagram 로그인 → 권한 허용**(instagram_business_basic·content_publish). 토큰은 부서가 안전한 곳에 저장(화면에 안 띄움).
5. 연결 뒤 부서가 계정 이름·ID 만 확인하고, 1단계 동안은 **게시하지 않는다**(리허설만).
