> 오너 원문: "새 계정을 통해 다양하게 무조건 조회 수 많이 나오도록"
> 이 안은 **조회 수가 높게 나오도록 설계**한 것이고, 실제 조회 수는 게시 후 수치로 확인한다. 예상 조회 수 숫자는 적지 않는다(근거 없음).
> 계정 **만들기·로그인·전화 인증은 오너 손**. 부서는 만들지 않는다.

## 고르는 기준
1. 실측 반응(인스타 해시태그 인기 게시물 좋아요 중앙값·유튜브 카테고리 인기 영상 조회 수)
2. **공식 출처(.go.kr·.or.kr 등)가 많아 검문 G1·G2를 통과하기 쉬운 주제** — 출처가 약하면 매일 보류만 쌓인다
3. 금칙(G3: 의료 단정·투자 권유·정치) 충돌이 적은 주제
4. 계정끼리 주제 겹치지 않음

## 부서 권고
- **먼저 3개(1·2·3)로 시작**, 2~4주 실제 조회 수를 본 뒤 4·5 추가 여부 결정. 근거: 1~3은 공식 출처가 풍부하고 금칙 충돌이 적어 자동 검문에서 덜 막힌다.
- 계정당 하루 1건으로 시작(PRD 상한 2). 같은 기기·같은 사람의 여러 계정이라 처음부터 많이 올리지 않는다(정책 조사 참고).
- **여러 계정 운영 위험(공식 확인, `T01_policy_research.md`)**: 한 계정이 정지되면 같은 소유자의 다른 계정도 제한될 수 있음(연쇄 정지) / 반복 콘텐츠는 빈도가 낮아도 제한될 수 있음 → 계정마다 틀(디자인·문장 구조)을 다르게 하고 같은 틀 대량 복제 금지 / 계정 자동 생성은 약관 위반 → 오너 손으로 생성. 앱 동시 로그인 최대 10개, API 게시 한도는 문서끼리 50·100건 불일치 → 50건으로 설계하고 게시 전 한도 조회값 사용. 계정은 비즈니스·크리에이터 전환 필요(Instagram Login 방식이면 페이스북 페이지 불필요).
- AI 표시: 이미지는 표시 의무 대상이 아니지만, API `is_ai_generated=true`(2026-06-22~) + 캡션 "AI로 제작"을 같이 쓴다.
- 모든 계정 캡션 끝 "AI로 제작" 표시, 낚시성 제목·남의 사진 사용 금지는 조회 수와 무관하게 유지.
